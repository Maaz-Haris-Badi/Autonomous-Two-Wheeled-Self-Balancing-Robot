# 🤖 Self-Balancing Two-Wheel Robot (STM32F3-Discovery)

This project implements a **fully functional self-balancing robot** using the on-board Inertial Measurement Unit (IMU) on the **STM32F3-Discovery** board. The firmware is developed using the **STM32 HAL Library** and configured via **STM32CubeMX**.

---

## ✨ Key Features

* **Reliable Tilt Angle Estimation:** Uses a **Complementary Filter** running at **100 Hz** to fuse accelerometer and gyroscope data for a stable angle. 
* **Real-Time Control:** **PID Controller** (angle $\rightarrow$ motor speed) executes at **100 Hz** for precise stabilization.
* **Dual DC Motor Control:** Utilizes **PWM** (TIM3 CH1 & CH2) for speed and GPIOs for direction control.
* **Bluetooth Interface:** **HC-06** module enables a command interface for live **PID tuning** and real-time data streaming.
* **Real-Time IMU Streaming:** Outputs raw and processed sensor data as **JSON** via Bluetooth.
* **Safety Fall Detection:** Automatically stops motors if the tilt angle exceeds **$\pm 45^{\circ}$**.

## 📡 Bluetooth Command Interface

Commands are **case-insensitive** and can be sent via any serial terminal connected to the HC-05/HC-06 module.

| Command | Example | Description |
| :--- | :--- | :--- |
| `KP <value>` | `KP 25` / `KP25` | Set Proportional Gain ($K_p$). Space is optional. |
| `KI <value>` | `KI 0.5` | Set Integral Gain ($K_i$). |
| `KD <value>` | `KD 1.2` | Set Derivative Gain ($K_d$). |
| `SETPOINT <deg>` | `SETPOINT 1.5` | Change the target angle (setpoint). |
| `STOP` | | **Emergency motor stop** (zeroes PWM). |
| `RESET` | | Resets the PID integral term and stops motors. |
| `STATUS` | | Displays a quick status overview. |
| `PARAMS` | | Shows all current PID parameters. |
| `IMU` | | Displays current sensor readings (raw & filtered). |
| `STREAM ON` | | Start continuous IMU JSON data stream. |
| `STREAM OFF` | | Stop continuous streaming. |
| `HELP` or `?` | | Shows the list of available commands. |

## ⚙️ PID Tuning Guide

Proper PID tuning is critical for stable balancing. The PID output, $u(t)$, which controls the motor speed, is calculated as:

$$
u(t) = K_p e(t) + K_i \int_{0}^{t} e(\tau) d\tau + K_d \frac{d}{dt} e(t)
$$

Where $e(t)$ is the error (SetPoint - CurrentAngle).

1.  Start with the integral and derivative gains set to zero: `KI 0`, `KD 0`.
2.  **Increase Kp** until the robot begins to **oscillate** or shake when disturbed.
3.  **Add a small Kd** value to introduce damping and **reduce/stabilize** the oscillations.
4.  **Add a tiny Ki** only if you observe a **steady-state error** (the robot doesn't settle perfectly upright).

> **Typical Working Values:** (Dependent on mechanical build)
> * $K_p$: 22–35
> * $K_i$: 0–80
> * $K_d$: 0.3–1.2

## 🛠️ Project Structure & Compilation

The project uses the standard structure generated by **STM32CubeMX** with HAL drivers.

* `Core/Src/main.c`: Contains the main application logic and the **Bluetooth command parser**.
* `Core/Src/stm32f3xx_it.c`: Implements the **TIM2 interrupt** which drives the **100 Hz sensor reading and filter loop**.

### Build & Flash

* **Toolchain:** STM32CubeIDE / Keil / Makefile.
* **Optimization:** Use `-O2` or `-Ofast` compilation flags for essential real-time performance.

### Calibration

The robot performs essential sensor calibration on every power-up:

* **Accelerometer Offset:** Measured while the robot is kept **level**.
* **Gyroscope Zero-Rate Offset:** Measured while the robot is kept **perfectly still** for approximately 7 seconds.

## 🐧 Bluetooth Setup on Ubuntu (Real-Time Plotting)

These steps allow you to connect the HC-05/HC-06 module to an Ubuntu laptop and use it as a virtual serial port (`/dev/rfcomm0`) for data logging and plotting.

### 1. Prerequisites
sudo apt update
sudo apt install bluetooth bluez bluez-tools rfcomm python3-venv

### 2. Pairing and Binding

#### Enable Bluetooth Service:
sudo systemctl start bluetooth

#### Scan and Pair:
bluetoothctl

# Inside the prompt:
scan on
# Note the MAC address (e.g., 98:D3:51:FE:A0:A3)
scan off
pair 98:D3:51:FE:A0:A3
trust 98:D3:51:FE:A0:A3
connect 98:D3:51:FE:A0:A3
exit

#### Bind to Serial Port (/dev/rfcomm0):
sudo rfcomm bind 0 98:D3:51:FE:A0:A3 # Use your MAC address

The robot is now accessible via /dev/rfcomm0.

### 3. Real-Time Plotting with Python
Use the virtual environment to install dependencies for the plot.py script:

#### Setup Virtual Environment:
cd /path/to/your/project
python3 -m venv robot_venv
source robot_venv/bin/activate
pip install pyserial matplotlib

#### Run Plotting Script:
source robot_venv/bin/activate
python plot.py

# On the robot, send the command: STREAM ON
#### Deactivate when done:
deactivate
